## Why this directory is mostly empty

The 6 drafted policies live as private working documents while we finalize wording with the fractional vCISO budgeted for Q3 2026. Drafts will be committed to this directory once they're signed and version-locked.

A SOC 2 Type I audit typically expects:
- All 12 policies authored and signed
- 6-month observation window of evidence
- External auditor walkthrough

GUARDIAN's roadmap (PROCUREMENT.md §2.2): policies 7-12 drafted in 2026-Q3, observation window opens 2026-Q4, Type I report issued 2027-Q1.
